# Theme Options

Theme is just copy (names, labels, messages), so it can change any time.

## Picked: immigration / visa theme
Inspired by "japa" (Nigerian slang for emigrating), but the game name avoids the word since most guests aren't Nigerian and wouldn't get it.

**Vocabulary (draft)**
| Game concept | Themed copy |
|---|---|
| Player | Applicant |
| Your 4-digit code | Visa stamp / case number |
| Elimination | **Visa denied** |
| Winner | Gets the **green card** |
| Players remaining | "18 applicants remain" |
| Target | Your case file |
| Mission | Interview task |
| Host (Afam) | Immigration officer / Consul |
| Ghosts | Deported / "back home" |
| Pause | "Embassy closed" |
| End reveal | "Final decisions" |
